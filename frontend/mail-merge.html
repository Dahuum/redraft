Frequently asked

What data formats can I use?

CSV or Excel. Each row becomes one PDF; you map the fields that change to your columns.

Do the generated PDFs keep the original font?

Yes. Every document rewrites the changed fields in the template's own font — no boxes, no drift.

Can each file be named automatically?

Yes. Pick a column — client name, invoice number — and each PDF is named from it.
